# OS-GO — Запуск в локальной сети (LAN)

## Что понадобится

- Python 3.10+
- PySide6 (`pip install PySide6`)
- websockets (`pip install websockets`)
- Ваши модули: `client_ad.py`, `server_ad.py`, `protocol_ad.py`, `output_interface_ad.py`, `go_engine`, `core_adapter`

## 1. Структура файлов

Положите все файлы в одну папку (или рядом с вашими модулями движка):

```
your_project/
├── server_ad.py
├── client_ad.py
├── protocol_ad.py
├── output_interface_ad.py
├── pyside6_go_client.py   ← наш GUI-клиент
├── go_engine.py           ← ваш движок
├── core_adapter.py        ← адаптер сессии
└── ...
```

## 2. Запуск сервера (на одном компьютере в сети)

### Шаг 1: узнайте IP-адрес сервера

**Windows (PowerShell):**
```powershell
ipconfig
# Ищите "IPv4-адрес" в активном адаптере Wi-Fi/Ethernet
# Пример: 192.168.1.105
```

**Linux/macOS:**
```bash
ip addr show
# или
ifconfig
# Ищите inet, например: 192.168.1.105
```

### Шаг 2: запустите сервер

```bash
python server_ad.py --host 0.0.0.0 --port 8765
```

- `--host 0.0.0.0` — слушать все интерфейсы (нужно для LAN)
- `--port 8765` — порт WebSocket

**Вы увидите:**
```
Starting server on ws://0.0.0.0:8765
```

### Шаг 3: разрешите брандмауэр

Если Windows Defender или антивирус блокирует — разрешите Python доступ к частным сетям.

## 3. Запуск GUI-клиента (на любом компьютере в сети)

### На том же ПК, что и сервер:

```bash
python pyside6_go_client.py
```

В поле "Сервер" оставьте: `ws://localhost:8765`

### На другом ПК/ноутбуке в локальной сети:

```bash
python pyside6_go_client.py
```

В поле "Сервер" введите IP сервера:  
**`ws://192.168.1.105:8765`** (подставьте ваш IP)

## 4. Как играть

1. **Создающий (Host)** — подключается, нажимает "Создать комнату", выбирает размер доски, жмёт "Готов".
2. **Присоединяющийся** — подключается к тому же IP, видит комнату в списке, выбирает её, жмёт "Войти", затем "Готов".
3. Когда оба нажали "Готов" — игра начинается автоматически.
4. Кликайте по доске для хода. Кнопки: Пас, Сдаться, Отменить ход, Чат.

## 5. Типичные проблемы

| Проблема | Решение |
|----------|---------|
| `Connection refused` | Проверьте IP и порт. Убедитесь, что сервер запущен и брандмауэр не блокирует порт 8765. |
| Пустой список комнат | Нажмите "Обновить". Убедитесь, что сервер видит подключение в консоли. |
| Игра не начинается | Оба игрока должны нажать "Готов" в комнате. |
| Не ставятся камни | Кликайте ближе к пересечениям линий. |

## 6. Быстрый тест на одном ПК

Можно запустить сервер и два GUI-клиента на одном компьютере:

- Сервер: `python server_ad.py --host 0.0.0.0 --port 8765`
- Клиент 1: `python pyside6_go_client.py` → `ws://localhost:8765`
- Клиент 2: `python pyside6_go_client.py` → `ws://localhost:8765`

Создайте комнату в первом клиенте, войдите во вторым — и играйте с самим собой для теста.
